🚀 Интеграция Tilda → СБИС (API для обработки заказов)
Этот проект представляет собой PHP-скрипт, который принимает данные о заказах из формы на сайте Tilda и отправляет их в систему СБИС (через API) для дальнейшей обработки. Используется для автоматизации приёма заказов в ритейле или доставке еды.

🔧 Основные функции:
Приём JSON-данных от Tilda через вебхук.
Валидация входящих данных (имя, email, телефон, товары и т.д.).
Автоматическое получение и сохранение токена доступа к СБИС.
Преобразование адреса доставки (включая перевод ent. → Подъезд, fl. → Этаж и др.).
Поиск товаров по названию в локальном файле all-products.json и формирование корректного списка номенклатуры.
Отправка заказа в СБИС с учётом самовывоза, времени доставки и количества персон.
Подробное логирование всех этапов в файлы (logs/...).

📁 Структура проекта:
.
├── api.php                  # Основной скрипт-обработчик
├── secrets.php              # Конфиденциальные данные (токены, ключи)
├── all-products.json        # База товаров: соответствие имени и nomNumber
├── logs/
│   ├── 1-sending_to_sbis_log.txt  # Логи запросов и ответов
│   └── api-error.txt              # Ошибки обработки

⚙️ Требования:
PHP 7.4+
cURL
Доступ к API СБИС (реквизиты в secrets.php)
Настроенный вебхук в Tilda

🛠 Как настроить:
Скопируйте репозиторий на сервер.
Создайте файл secrets.php с такими данными:
php
<?php
return [
    'SBIS_TOKEN_FILE' => __DIR__ . '/sbis_token.json',
    'SBIS_APP_CLIENT_ID' => 'ваш_client_id',
    'SBIS_APP_SECRET' => 'ваш_app_secret',
    'SBIS_SECRET_KEY' => 'ваш_secret_key'
];
Убедитесь, что папка logs/ существует и доступна для записи.
Укажите URL к api.php как endpoint вебхука Tilda.

✅ Тестирование
Отправьте тестовый запрос:

json
{
  "test": "test",
  "Name": "Иван",
  "Mail": "test@example.com"
}
— Сервер ответит {"status": "success", ...} и запишет событие в лог.
